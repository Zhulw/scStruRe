# Data directory

The benchmark H5AD files are not redistributed in this repository.

Place each standardized dataset under `data/`, for example:

```text
data/
├── zeisel.h5ad
└── Zeisel/
    └── graph/              # generated by build_graph.py
```

The input H5AD file must satisfy the following requirements:

- rows are cells and columns are genes;
- `adata.X` contains the model input expression matrix;
- the evaluation label is stored in `adata.obs` (default key: `cell_type`);
- cell order is unchanged between graph construction and training;
- if `adata.raw` is available, `build_graph.py` uses `adata.raw.X` to recover
  the full-gene matrix for graph construction; otherwise it uses `adata.X`.

Reference labels are used by the released program for stratified data splitting,
post-clustering metrics, and optional graph diagnostics. The cluster count is
passed explicitly with `--n_clusters`.

Generated graph files and H5AD files are ignored by Git to keep the repository
small and to avoid redistributing third-party datasets.
